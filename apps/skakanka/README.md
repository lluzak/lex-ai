# Skakanka HIIT

Prosty minutnik interwałowy do treningu na skakance (jeden plik, bez zależności).
Otwórz `index.html` w przeglądarce.

- 4 gotowe plany (początkujący, średniozaawansowany, zaawansowany, Tabata) i plan własny.
- Sygnały dźwiękowe (Web Audio): 3-2-1 przed każdą zmianą, wysoki ton na start pracy, niski na odpoczynek, melodia na koniec.
- Opcjonalny głos lektora (po polsku, jeśli przeglądarka ma polski głos) i sygnał w połowie interwału.
- Pauza / dalej / wstecz, skróty: spacja, strzałki, Esc.
- Ekran nie gaśnie w trakcie (Wake Lock, gdzie przeglądarka na to pozwala).
